What is the reason of
    def _is_unit_on_map(self, unit):
        return bool(unit.is_on_map and unit.position and None not in unit.position)
The method `_is_unit_on_map` is designed to check whether a given unit is currently present on the game map. It does this by evaluating three conditions:
1. `unit.is_on_map`: This checks if the unit is flagged as being on the map. If this attribute is `True`, it indicates that the unit is intended to be on the map.
2. `unit.position`: This checks if the unit has a defined position. If the position attribute is not `None`, it means the unit has a specific location on the map.
3. `None not in unit.position`: This checks that the position attribute does not contain any `None` values. This ensures that the unit's position is fully defined and valid.
But then, what do we need unit.is_on_map for? If we already check if the unit has a defined position and that it does not contain any `None` values, the `unit.is_on_map` attribute may seem redundant. However, it serves as an additional safeguard to explicitly indicate whether the unit is intended to be on the map, regardless of its position. This can be useful in scenarios where a unit might have a valid position but is not actively participating in the game (e.g., it could be in a reserve state or temporarily removed from play). Therefore, while the position checks are important for validating the unit's location, `unit.is_on_map` provides a clear and explicit flag for the unit's status on the map.
And cannot we just check if the unit has a defined position and that it does not contain any `None` values? Yes, we could rely solely on the position checks to determine if a unit is on the map. However, using `unit.is_on_map` adds clarity and explicitness to the code. It allows developers to quickly understand the intended state of the unit without having to infer it from its position alone. This can improve code readability and maintainability, especially in complex game logic where units may have various states and conditions affecting their presence on the map.
